# FlexTube Automation Cell

An independent industrial automation simulation project.

## Objective
Develop a simulated manufacturing cell integrating:
- Siemens PLC control
- KUKA robotic handling
- Industrial HMI
- C++ machine monitoring
- Fault handling and testing

## Project Status
Phase 1: Requirements and system design.
