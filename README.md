# FlexTube Automation Cell

An independent industrial automation simulation project.

## Objective
Develop a simulated manufacturing cell integrating:
- Siemens PLC control
- KUKA robotic handling
- Industrial HMIa
- C++ machine monitoring
- Fault handling and testing

## Project Status
Phase 1: Requirements and system design.

## Disclaimer
Educational simulation project.
## Project Objectives

- Siemens PLC programming using TIA Portal
- Industrial robot integration using KUKA
- HMI development using WinCC and Qt/C++
- Automated tube bending and handling
- Machine monitoring and industrial communication
